# 论，我。

在第一个博客里，我也写过一篇自我介绍。现在的我与那时已有了许多改变，故而也许可以称此文为第一篇。



## Bowking_ED a.k.a. 荷見羽  a.k.a. minami

现实里是阴晴不定一般通过 DK。没有拿得出手的特长，但涉足~~入门~~了很多领域。自认为没有太过乖戾孤僻的性格，正常情况下是很好相处的。缺点是说话口齿不清，一般人要听我说三遍才能听懂~~，但是 minami 语十级可以秒懂~~。

网上的我和现实里没什么不同，只不过有了更多达意的方式而已。不在意所有人喜不喜欢我，至少我很开心。

标题是我最常用的几个马甲。有一段时间，我很喜欢给自己起马甲，再给它们分好职责，在什么场合用哪个，诸如此类。现在已经不对那种东西很感兴趣了。但那毕竟是曾经花了一些心血取的名字~~和开的小号~~，又不舍得就此丢弃，故我会随机地使用它们。

## 喜欢的东西

- **计算机和网络相关**。从小就喜欢鼓捣这些东西，然而十余年也没鼓捣出个所以然来。目前的水平是能在完全不接触计算机的人面前装一装和在信息课考试里被别人问问题的程度。
- **音乐游戏**。说节奏游戏可能更精准一点。曾经较为精通的包含 Phigros、Arcaea、osu!std 以及 4Keys 下落式等，目前是很纯粹的舞萌痴。
- **東方プロジェクト**。游戏方面，目前主练风神录 N 面混关（四面真难吧）和绯想天则；同人音乐方面，最爱的社团是 FELT。
- **Galgame**。《千恋万花》入坑，最近推完的是《青空下的加缪》。计划表里有很多想推的，但是完全没时间。
- **2D RPG**。如《东方年代记》《Blacksouls》《ib》等。~~以上都没玩完。~~
- **哲学与精神分析**。特别是马克思主义、后现代哲学和拉康。虽说如此，但也没读过什么书——没有亲历过的人，读再多的书又有什么用呢？
- **现代诗**。喜欢的诗人包含顾城、戈麦和许立志，以及目前活跃在 bilibili 的[叙矣I](https://space.bilibili.com/1824700)和[口口](https://space.bilibili.com/8101947)。我也经常照猫画虎，但成果貌不似，神也离。
- **音乐**。虽说是音游玩家，但已经多少对 Hardcore 无感了。什么歌都听，好听的歌请多多推荐给我。华语听得不多~~*（除了中 V）*~~，唯一喜欢的 *比较* 流行的歌手是陈鸿宇，虽然也只是喜欢他的一张专辑而已。
- **其它**。我热衷于接触新事物，包括写博客。但从未有一深入过，因此目前一事无成。
